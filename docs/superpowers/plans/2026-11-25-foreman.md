# Foreman Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the `foreman` skill, a method for running a job to the end with cheaper workers while the user is away, and make `opencode-delegate` able to start a turn that reports its end in a file, so a finished worker is never missed.

**Architecture:** `opencode_turn.py` gains `--status-file`, `--detach` and a SIGTERM cancel. A new worker-agnostic `wait_status.py` reads that status file (and the log's age) in one call. `foreman/SKILL.md` holds the method and links three references (intake, run loop, waiting). All state of a run is in files, so a run can resume.

**Tech Stack:** Python 3.11 or later (stdlib only), pytest run with `uv`, Markdown skill files.

**Spec:** `docs/superpowers/specs/2026-11-25-foreman-design.md`

## Global Constraints

- Scripts are stdlib Python 3.11 or later and put their own folder on `sys.path` for tests through `tests/conftest.py`.
- Test command per skill, from the repo root: `uv run --no-project --python 3.12 --with pytest pytest skills/meta/<skill>/tests -q`. Tests never call a model provider.
- `SKILL.md` frontmatter `name` equals the folder name; `description` starts with `Use when` and is at most 1024 characters; every `SKILL.md` has the `## Reporting problems with this skill` section (checked by `skills/meta/report-skill-issue/tests/test_repo_hooks.py`).
- Code, docs, comments and commit messages are in English. Commits are Conventional Commits with the skill as the scope (`feat(foreman): …`, `feat(opencode-delegate): …`), one commit per task.
- The repo is public: no home path, private path or project content in any tracked file.
- Default interval between checks of a running worker: **40 minutes = 2400 seconds**. The default stall limit equals the interval.
- Exit codes: `opencode_turn.py` 0 done or stopped, 1 failed, 2 timeout, 3 could not start, **4 cancelled**; `wait_status.py` 0 finished, **10 running**, **11 stalled**, 3 bad usage.
- Status line format (unchanged): `status=<done|stopped|failed|timeout|cancelled> exit=<n> log=<path>`.
- Files of a run: `brief.md` (with `Status: go`), `progress.md`, `decisions.md`, `skill-problems.md`, under `<work>/` (default `<cwd>/.foreman/<slug>/`).
- Default retry rule: the foreman takes a unit over after the worker fails the same check twice.

## Review Focus

Failure modes the spec implies that no requirement states; each has a test in the task named:

1. A status file left by an earlier turn is read as the new result (Task 1: removed when a turn starts).
2. `--detach` with a bad folder or a missing `opencode` fails silently inside the detached child (Task 2: exit 3 before detaching).
3. A reader sees a half-written or empty status file as "finished" (Task 1: atomic write; Task 4: an empty file counts as running).
4. At the first wake-up the log does not exist yet, or the status file's folder does not (Task 4: no crash, not stalled early; Task 1: parent folders are created).
5. Cancelling a detached turn leaves `opencode` and its children running, or leaves no status behind (Task 1).

### Task 4: `wait_status.py`

**Files:**
- Create: `skills/meta/foreman/scripts/wait_status.py`, `skills/meta/foreman/tests/conftest.py`, `skills/meta/foreman/tests/test_wait_status.py`

**Interfaces:**
- Produces: `main(argv: list[str] | None = None) -> int` with `--status-file F` (required), `--log L`, `--max SECONDS` (default 0), `--stall SECONDS`, `--poll SECONDS` (default 1.0). It prints one line:
  - status file present and non-empty: its first line, exit 0;
  - else, log older than `--stall`: `stalled log-age=<n>s`, exit 11 (this wins over `--max` being reached);
  - else after `--max` seconds: `running log-age=<n>s` (or `running log-age=unknown` without `--log`), exit 10;
  - `--stall` without `--log`: message on stderr, exit 3.
  - A log that does not exist yet has an age counted from the start of the call.
- `conftest.py` puts `scripts/` on `sys.path` and provides the `SKILL_DIR` constant and a `wait_until` helper like Task 1's.

- [ ] **Step 1: Write the failing tests** in `test_wait_status.py` (use `capsys` and `os.utime` to age a log):
  - `test_a_finished_turn_prints_its_status_line_and_exits_0` (also for a `status=failed` line);
  - `test_an_empty_status_file_counts_as_running`;
  - `test_no_status_file_and_max_0_is_an_instant_running_check_exit_10`, with and without `--log`;
  - `test_a_log_older_than_the_stall_limit_is_stalled_exit_11`;
  - `test_stalled_wins_over_max_being_reached`;
  - `test_the_status_file_wins_over_a_stale_log`;
  - `test_a_log_that_does_not_exist_yet_is_not_stalled_before_the_limit_and_does_not_crash`;
  - `test_a_positive_max_returns_as_soon_as_the_status_file_appears`: a thread writes the file after 0.3 s, `--max 5 --poll 0.1`, returns 0 in under 2 s;

  - `test_stall_without_log_is_exit_3`.
