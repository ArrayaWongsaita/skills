# ADR 0001: CLI-first skill library layout

- Status / สถานะ: Accepted / ยอมรับแล้ว
- Date / วันที่: 2026-08-03

## Context / บริบท

This repository is a personal collection of reusable agent skills. Skills must be easy to install from GitHub with `npx skills add`, understandable to humans, and maintainable as the collection grows.

repo นี้เป็นคลัง skill ส่วนตัวที่ต้องติดตั้งจาก GitHub ได้ง่ายด้วย `npx skills add`, อ่านเข้าใจได้โดยคน และดูแลต่อได้เมื่อจำนวน skill เพิ่มขึ้น

The working tree already contains two current skills under different domains, while the previous Codex plugin and custom symlink installer are no longer part of the intended workflow.

## Decision / การตัดสินใจ

1. `skills/<category>/<skill>/SKILL.md` is the agent-facing source of truth.
2. Each skill has one primary category and one human guide at `docs/skills/<category>/<skill>.md`.
3. Installation is CLI-first. README examples use `npx skills add ArrayaWongsaita/skills`; no custom installer or Codex plugin is required.
4. Category installation is represented by repeated `--skill` flags because categories are repository metadata, not a CLI filter.
5. `docs/skills/README.md` is generated by `npm run docs:index` and checked for drift by `npm run validate`.
6. Node-based tests, validation, and GitHub Actions are the quality gate.

## Consequences / ผลที่ตามมา

### Positive / ข้อดี

- Agent instructions and human documentation have separate audiences and responsibilities.
- Install commands stay compatible with the public `skills` CLI.
- The generated index makes new skills discoverable without maintaining a second manual registry.
- Validation catches missing guides, duplicate names, and stale category commands.

### Trade-offs / ข้อแลกเปลี่ยน

- Adding a skill requires both `SKILL.md` and its guide.
- Category install commands must be regenerated after skill changes.
- A skill belongs to one primary category; cross-cutting discovery belongs in descriptions and future tags, not duplicate directories.

## Rejected alternatives / ทางเลือกที่ไม่เลือก

- A Codex-only plugin as the primary distribution mechanism.
- A repository-owned symlink installer that duplicates the `skills` CLI installation workflow.
- A single large README section instead of one guide per skill.
