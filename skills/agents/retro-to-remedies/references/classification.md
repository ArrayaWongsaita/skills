# Classification and Remedies

Miss classification translates each failure pattern into a distinct environment Remedy kind: mechanical misses become automated Checks, judgement misses become Standards recorded in `CODING_STANDARDS.md` or Reuse Catalog rules, documentation navigation misses become Pointers, missing developer information becomes Access, stale instructions become Prunes, and flaws in a skill's instructions become Skill fixes. Any Failed Remedy whose miss recurred despite prior application escalates to a stronger Remedy kind.
