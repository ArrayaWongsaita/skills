# Retro Report Format

The Retro report written to `.scratch/<feature-slug>/retro.md` synthesises read and missing sources, followed-up pending items, ranked Remedies with verbatim evidence and proposed changes or prompts, Carried findings, and Open bugs. A `Choice:` prompt for each Remedy records the human decision (`apply`, `hand off`, `decline`, or `defer`) during the pause after Stage 1.
